# Genetic-simulator
This programme was built to give a heuristic representation of the spread of genetic traits and diseases across generations. It is important to note that it is a highly simplified version, which represents and gives insight into the general principals of genetics. It is not meant as a scientific tool and does represent medical realities.

The programme's design is based on the data architecture of relational databases. It is written entirely in the programming language Python, but could be used in concord with SQL according to the user's preferences. This possibilty has not been included in the scope of this project.

the programme first creates, on a random basis, genes which is tied to an eventual chromosome and loci (location of gene on chromosome) and is assigned a trait, disease, or a score for polygenic (caused by an interaction of genes). For each loci, there are multiple gene versions. Next, chromosomes are formed through a random selection of genes for each loci. Hereafter, a starting population is created, assigning a random selection of chromosome version to each person. This starting population is assigned the generation code 0. Each following generation is assigned a sequential number. These generation are created by selecting a male and female individual of reproductive age and randomly selecting half the genome of each and combining them into a new person. Physical gender of an individual is assigned based on the allosomal chromosomes assigned during the generation. In other words, the genetics behind physical gender is integrated in the genetic heuristic algorhitm. The state of each new generation is interpreted through another set of algorithms and analysed through use of statistical methods and further visualzed in a network map. THese statistics and visualizations are in still in development.

The concepts integrated into this programme and the assumptions and scientific theories on which the heuristics are based, are the following:
- A human has 23 pairs of chromosomes, of which one pair determines physical gender. Each chromosomes consists of a large collections of genes, which are bound to given locations on the chromosome. It is to be noted that in reality, the locations of a gene can and often does shift due to genetic mutations. This sort of mutation is not included in this project. The genes encode, through complex processes which are greatly simplified, traits. This programme assumes that a gene causes or contributes to traits and do not change their effects in the presence of other genes, which in reality, happens often.
- Each loci on a chromosome, except for the ones that whose exact function essential for compatibility with life, has multiple variants, refered to as genes. To account for genes that cannot weather mutations, the number of genes on each chromosome is far lower than in reality. Each gene has DNA string, encoding a protein, which leads to a trait or disease.
- In human reproduction, every individual receives one chromosome of each pair that either parent possesses. For example, for the chromosome pair 2, the mother has version 1 and 2 and the father 3 and 4, the child can have the combinations 1-3, 1-4, 2-3, and 2-4. The selection of the chromosomes from each pair is random. If both parents pass on the same version of a chromosome, the homozygosity (number of genes of which both version are the same) increases. Scientific evidence shows this greatly increases the risk for disease. The effects of culturally accepted degree of kinship for reproduction, as well as the effects of a limited population can be simulated within this programme
- The effects of genes can roughly be divided into three categories, dominant, recessive, and polygeneic. Dominant means that the presence of a single gene in a gene pair is always expressed. Recessive means that a gene pair needs both sides of the pair to be the same for the trait to be expressed. Polygeneic means that a trait is caused by a complex interaction of genes all throughout the genome.
- Mutations occur in every generation. The most common type are single base mutation. One nucleic acid is wrongly transcribed and turned into another nucleic acid. The DNA string of each gene is assigned during the initial generation. This programme randomly selects a genes and changes a single base. It checks of this version of the gene already exists and if so, its effects are read as the already existing version. Else, new effects are assigned to the gene. The offspring receives the genes with the mutated version, thus creating the possiblity for traits that were not present in the starting population.
- -Another type of mutation is the chromosome crossover. In this phenomenon, a section of a chromosome is switched with the section of the other chromosome in the pair. This does not or rarely creates new genes. In this programme, it is assumed new genes are not created. However, this type of mutation does create a new chromosome and thus combinations of genes that were not previously possible in the population.
- In reality, a base pair can be lost, which cause a shift in the whole of the chromosome. This is called a frameshift mutation. As this can affect all genes on the chromosome and their effects, the programme does not currently possess the complexity to reflect this sort of mutation and the choice has been made to disregard it.
